# Harmony Genius Architecture

Harmony Genius follows a hybrid three-layer architecture.

## Layer 1: User Layer

Mobile users interact with the platform through the Harmony Genius mobile application.

Primary user groups:
- Choir singers
- Choir directors
- Music creators
- Music listeners

## Layer 2: Platform Infrastructure

The mobile platform includes:

- Music Reels (short musical videos)
- Choir Workspace (digital rehearsal room)
- Music Marketplace
- Creator Upload Studio
- Social music interaction

Backend services include:
- Audio streaming
- User authentication
- Mobile money payments
- Recommendation engine

## Layer 3: Blockchain Transparency Layer

Blockchain is used only for ownership and attribution records.

This layer supports:
- Song metadata registration
- Creator identity verification
- Transparent royalty attribution ledger

Streaming and payments remain on conventional infrastructure to preserve usability, speed, and accessibility in low-bandwidth environments.

## Planned Stack

- Mobile App: React Native or Flutter
- Backend: Python / FastAPI
- Cloud: AWS
- Database: PostgreSQL
- Storage: AWS S3
- Blockchain: Ethereum-compatible Layer 2 / scalable public blockchain
